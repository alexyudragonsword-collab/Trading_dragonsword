# Sector Management

管理 `universe.py` 中的两级股票池结构（顶级板块 → 子板块）。

## 数据结构说明

`universe.py` 使用两级结构：
- **顶级板块**（`SECTOR_MAP` 的 key）：当前为 `半导体`、`科技`
- **子板块**（每个顶级板块下的 key）：如 `Memory`、`Magnificent Seven`、`中国科技股` 等

参数 `$ARGUMENTS` 可以是顶级板块名或子板块名。

## 用法

```
/sector <名称>
```

示例：
- `/sector 半导体`              ← 顶级板块，查看/管理整个半导体板块
- `/sector 科技`                ← 顶级板块，查看/管理整个科技板块
- `/sector Memory`              ← 子板块
- `/sector 中国科技股`           ← 子板块
- `/sector Magnificent Seven`   ← 子板块
- `/sector AI Infrastructure`   ← 新子板块示例

## 执行步骤

**参数：** $ARGUMENTS

### 1. 判断参数类型

读取 `universe.py` 中的 `SECTOR_MAP`，判断 `$ARGUMENTS` 属于哪种情况：

**A. 匹配顶级板块**（如 `半导体`、`科技`）：
- 列出该顶级板块下所有子板块及其股票数量
- 询问用户想操作哪个子板块，或是否新建子板块
- 转入对应子板块的操作流程（见 B / C）

**B. 匹配子板块**（如 `Memory`、`中国科技股`）：
- 显示该子板块归属的顶级板块
- 列出当前所有股票，格式为表格（代码 + 公司全名）
- 标注去重说明：若该子板块有股票因全局去重被其他子板块优先占用（如 NVDA 在 Magnificent Seven 中展示但主归属为半导体），需说明
- 询问用户想执行哪种操作：
  - **添加股票**：用户提供代码，确认交易所格式，写入该子板块
  - **删除股票**：用户指定代码，从该子板块移除
  - **替换股票**：删除旧代码，添加新代码
  - **重命名子板块**：修改 `SECTOR_MAP` 中对应 key
  - **移动子板块**：将整个子板块移至另一个顶级板块
  - **删除整个子板块**：移除该子板块及其所有股票（需二次确认）
  - **仅查看**：不做修改，结束

**C. 未匹配任何已有板块**（新子板块）：
- 询问用户确认名称
- 询问归属哪个顶级板块（`半导体` 还是 `科技`，或新建顶级板块）
- 若新建顶级板块：在 `SECTOR_MAP` 中新增顶级 key
- 在对应顶级板块下新增子板块，初始为空列表
- 询问要添加哪些股票（代码 + 确认交易所格式）
- 将股票写入新子板块

### 2. 执行修改并提交

如有任何修改，更新 `universe.py`，然后 commit 并 push 到当前分支。

## 注意事项

- 公司名称从已知知识库提供，不调用外部 API
- 非美股需确认正确的 yfinance 后缀格式：
  - 港股：`XXXX.HK`
  - 韩股：`XXXXXX.KS`
  - 台股：`XXXX.TW`
  - 上交所：`XXXXXX.SS`
  - 深交所：`XXXXXX.SZ`
- **去重规则**：同一股票在 `ALL_TICKERS` 中只出现一次，以 `SECTOR_MAP` 中第一次出现的子板块为主归属；展示时（`SECTOR_MAP` 直接渲染）允许跨子板块重复显示（如 NVDA 同时出现在 Fabless Design 和 Magnificent Seven）
- `scorer.py` 的 `FACTOR_GROUPS` / `DEFAULT_GROUP_WEIGHTS` 与股票板块结构无关，新建板块无需修改评分引擎
- 不要创建 Pull Request，除非用户明确要求
